# 번역과 표시

번역 원본은 [i18n](../i18n/)이며 지원 언어 목록은 [locales 계약](../../../backend/src/main/resources/contracts/locales.json)에서 관리한다. UI 문구, 게임 명칭·툴팁, 베이스 표시, 증강물 표시, 옵션 템플릿과 장비 분류 번역을 구분한다.

화면 표시용 이름·설명과 출처 원문은 보존한다. 향후 송수신은 짧은 ID를 사용하고 표시 시 번역을 찾는다. 서로 다른 항목이 같은 번역을 가진다는 이유로 같은 ID를 부여하지 않는다. 언어 변경으로 ID를 변경하지 않는다.

옵션 템플릿의 숫자 자리, source stat 단위와 대응 관계를 검증한다. 숫자를 임의 보정하거나 미해석 줄을 지우지 않는다. 미검토 raw stat을 지원하는 의미로 번역하지 않는다. 텍스트 가져오기는 검토된 영어 게임 복사 텍스트 경로를 따르고 UI 지원 언어 전체의 파싱 지원으로 확대 해석하지 않는다.

수집 자료는 검토용이다. 현재 번역을 자동 덮어쓰지 않고 출처·누락·기존 번역·단위·coverage를 검토한 뒤 반영한다. 원문 HTML과 과거 검증은 [legacy](../../legacy/)에 보관한다. 이미지 출처와 라이선스도 보존한다.
