# 소켓과 증강물

[augments](../game-data/crafting/augments/items.json)는 등록 항목, [augment-crafting](../game-data/crafting/augments/rules.json)은 홈 귀속·제작/접미 한도·최대 품질·Rune 효과·Idol 결속·전용 풀·배율의 원본이다.

장착 ID, 장비 분류, 실제 슬롯과 동일 아이템 제한을 검증한다. 캐릭터 전체 장비 제한이나 전체 전투를 계산하는 기능은 아니다. Perfect 선택 정책으로 숨긴 하위 Rune도 기존 저장 기록에는 남긴다. 홈 귀속 항목은 일반 교체로 제거하지 않는다.

증강물 제거만으로 이미 생성한 Crafted 옵션이나 보존 대상 초과 품질을 삭제하지 않는다. 특수 풀의 원래 정의를 보존하고 장착 여부에 따라 자격·가중치를 활성화한다. 미장착 정의의 가중치는 0이다.

`poolWeightPolicy.weightPerTier`는 사용자 지정 임시 가중치이며 공개된 게임 확률이 아니다. 값은 JSON에서 읽고 문서에 중복 관리하지 않는다. 군왕의 합금 저항 증폭 등 `magnitudeRules`는 공통 계산을 사용하며 고정 옵션은 제외한다.

미지원 원소 변환을 표시만으로 지원한다고 추정하지 않는다. 새 메커니즘은 단일 제작뿐 아니라 일반/훼손·반복·확률·저장 복원·텍스트·스냅샷의 직접 영향을 검증한다.
