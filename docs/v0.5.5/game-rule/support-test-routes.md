# 제작지원 테스트의 경로 계산 규칙

`/support-test`에서 베이스, 아이템 레벨, 희귀도, 시작 옵션과 목표를 설정한다. 백엔드는 시작 아이템에서 목표 옵션을 얻을 수 있는 순서를 찾고, 각 순서를 실제 제작 규칙으로 검증한다. 계산에는 모델 호출이 필요 없다.

## 옵션과 획득처

목표 옵션에는 번호를 붙인다. 같은 번호는 같은 옵션을 가리킨다. `X`는 시작 아이템에 이미 있지만 목표에 필요하지 않은 옵션이고, `F`는 분열된 옵션이다. 접두·접미의 자리와 실제 옵션 계열은 제작 중에도 유지해서 판단한다.

| 표기 | 옵션을 얻는 방법 |
|---|---|
| B | 현재 베이스의 일반 풀에서 추첨한다. |
| E | 승급형 에센스로 마법 아이템을 희귀로 올리면서 일반 명시 옵션을 얻는다. 제작 옵션 한도 소모는 0이다. |
| C | 교체형 에센스, 합금, 감정액으로 제작 옵션을 얻는다. 이들은 같은 제작 옵션 한도를 쓴다. |
| D | 훼손 재료를 사용한 뒤 실제 공개 후보에서 옵션을 선택한다. |
| A | 해당 증강물을 장착해 열린 전용 옵션 풀에서 추첨한다. |

옵션 하나에 가능한 획득처를 모두 고려한다. 예를 들어 2번을 B로도 D로도 얻을 수 있다면 두 방법 모두 2번의 후보가 된다. 베이스 고정 옵션은 획득 순서에서 제외하고 목표 수치 판정에는 반영한다.

B와 A에는 티어의 등장 빈도를 붙인다. 테스트 기본값은 L이 1% 미만, M이 1% 이상 10% 미만, H가 10% 이상이다. 기준은 같은 베이스·아이템 레벨에서 같은 쪽(접두 또는 접미)에 등장할 수 있는 옵션들의 총가중치다. A는 해당 증강물로 열리는 풀도 포함한다. 이 수치는 옵션을 보호할지 판단하는 기준이다. 개별 제작 단계의 성공 확률은 그 시점의 슬롯과 징조, 실제 후보 풀로 다시 계산한다.

## 카드 선별과 획득 순서

1. **카드가 시작 아이템과 양립하는지 확인한다.** 시작 아이템에 분열 옵션이 있으면 그 옵션을 그대로 포함하는 카드만 남긴다. 예를 들어 분열 접두 1번을 다른 티어로 바꿔야 하는 카드는 여기서 탈락한다. 제작 옵션이 여러 개 필요하면 각 목표의 모든 획득처를 대조한다. 일반 풀로 한 목표를 얻어도 되는 경우에는 그 목표가 제작 한도를 차지한다고 가정하지 않는다. 제작 한도를 늘려야만 가능한 조합은 장비에 아스트리드의 룬(Astrid’s Creativity)을 장착할 수 있어야 하고, 늘어난 한도가 필요한 제작 전에 실제로 장착해야 한다.
2. **목표를 얻는 순서를 열거한다.** `2 → 4 → 3`은 실제로 2번, 4번, 3번을 얻은 순서다. 첫 추첨에서 3번을 얻으면 3번부터 시작하는 경로에 해당한다. 징조 사용이나 제거용 임시 옵션 준비는 제작 단계에 들어가며 목표 번호를 추가하지 않는다.
3. **각 경로의 제작과 확률을 검증한다.** 매 단계의 아이템에 해당 화폐와 징조를 쓸 수 있는지 확인하고, 실제 결과에서 원래 목표를 만족하는지 판정한다. 이미 목표를 만족하면 화폐 없이 종료한다. 경로는 검증된 성공 확률을 기준으로 정렬한다. 훼손 옵션처럼 선택 가능한 결과는 확인했지만 공개 확률이 알려지지 않은 경우에는 경로만 표시하고 확률은 미확정으로 둔다.

테스트 탭은 한 요청에서 검토할 카드와 제작 결과 수에 한도를 둔다. 한도에 닿으면 그때까지 확인한 경로를 부분 결과로 표시한다. 예를 들어 ‘특정 옵션이 없어야 함’처럼 제거만으로도 달성할 수 있는 목표는 획득 순서만으로 모든 해법을 확인하기 어렵다. 기폭제 품질에 따른 목표 수치를 검증할 수 없는 경우에도 미확정으로 표시한다. 부분 결과에서 경로가 비어 있어도 목표가 불가능하다고 판정하지 않는다.

## 이미 확보한 옵션을 잃을 수 있을 때

- **F**는 시작부터 보유한다. 그대로 유지하는 동안 획득 순서에 넣지 않는다.
- **M·H**는 보존하는 경로와 잃은 뒤 다시 얻는 경로를 모두 허용한다. 시작부터 있던 1번을 4번 획득 중에 잃고 이후 복구했다면, 순서에 `4 → 1`이 들어간다.
- **L**은 준비 단계를 거쳐서라도 보호한다. 예를 들어 접두에 드문 목표 옵션과 X가 있고 다음 목표를 에센스로 얻어야 한다고 하자. 제거 가능한 접미를 먼저 붙이고 접미 제거 징조를 써서 목표 접두를 보존할 수 있으면 이 방법을 쓴다.
- 보호할 수 있는 준비나 행동이 없을 때만 L을 잃을 위험을 허용한다. X가 빠지면 계속 진행한다. L이 빠지면 그 결과는 실패로 끝내며, L을 다시 얻는 복구 경로는 만들지 않는다. 성공 확률은 L이 사라지는 결과까지 포함한 전체 확률에서 계산한다.
