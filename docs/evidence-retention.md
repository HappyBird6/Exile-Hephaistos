# 근거 자료 관리 기준

현재 자료는 [docs/evidence/0.5.5](evidence/0.5.5/README.md)에 기능별로 관리한다. 이전 버전의 수집 이력·QA 로그·배포 결과·외부 ZIP 백업 목록은 저장소에서 제거했다.

유지하는 것은 현재 도구와 검사가 소비하는 옵션·가중치·언어별 원문·출처 URL·내용 해시, 규칙 의미를 확인하는 자료와 독립 회귀 입력이다. 원문 HTML의 실제 bytes와 해시 검증을 보존한다. JSON에서는 과거 수집 시각과 freshness metadata를 제거하며 파일 자체의 현재 hash를 쓰는 이미지 인덱스도 함께 갱신한다.

## 분류와 이름

- 아이템별 bundle이나 날짜별 폴더를 만들지 않는다. 번역은 i18n, 수치/가중치는 catalog, 제작 수단은 crafting, 화면은 workbench처럼 기능으로 묶는다.
- 폴더·파일명은 날짜 없는 소문자·하이픈을 사용한다. 언어는 en/ko/zh-cn/zh-tw/ja/es로 통일한다.
- 같은 파일을 여러 기능이 쓰면 한 곳에 보관하고 file-index.json으로 연결한다. 입력 원문을 중복 복제하지 않는다.
- 실제 원문과 simulator 가정, 관리 버전과 게임 검증 상태를 구별한다. 0.5.5 폴더로 옮겼다는 이유로 기존 UNVERIFIED 상태를 바꾸지 않는다.

## 변경 검증

이동할 때는 사용 중인 테스트·importer·수집/이미지 도구·문서의 경로를 함께 갱신한다. 원본 수치/weight·원문·URL 보존, HTML bytes, JSON 해석, 인덱스/참조의 파일 존재와 중복을 검사한다. 봉인된 앱 metadata를 바꿨다면 정식 manifest 갱신과 관련 loader·통합 검사도 수행한다. 이전 실행의 테스트 통과 기록을 현재 검사 결과로 옮기지 않는다.
