# 히스토리와 세션 오버뷰

2026-11-06. 제작 세션은 브라우저에 보관하며, 다른 브라우저로 전달할 때는 JSON 파일의 import/export를 사용한다. 공유 링크 UI·서버 API·파일 저장 설정은 제거했다. 서버에 이미 존재하던 공유 파일은 자동으로 삭제하지 않는다.

## 제작 작업대의 탭

작업대 내부의 기본 탭은 **시뮬레이션**이다. **히스토리** 탭은 🕘 세션 라이브러리 / ⭐ 즐겨찾기 사이드 내비게이션으로 기록을 탐색한다. 탭 전환과 세션 미리보기는 현재 제작 세션·cursor·draft를 변경하지 않는다.

세션을 선택하면 마지막 Frame의 최종 아이템을 미리 보여준다. **시뮬레이션에서 이어하기**를 눌러야 해당 세션의 마지막 Frame을 작업대에 적용하고 시뮬레이션 탭으로 돌아간다. 제목 수정·즐겨찾기·세션별 삭제·삭제 되돌리기는 기존 저장 경로를 사용하며, 저장 실패는 완료로 표시하지 않는다. 반복 제작 중에는 탭 이동과 저장 데이터 변경을 차단한다.

## 세션 오버뷰

기존 세션 히스토리 페이지의 이름은 **세션 오버뷰**로 변경했다. 각 기록과 현재 작업대의 `wb-session-notation` 제목 행 오른쪽 버튼에서 `/history/:sessionId`를 연다. 이 주소는 해당 브라우저의 기록을 읽는다. 오버뷰의 복귀 링크는 작업대의 히스토리 탭을 연다.

최초 상태와 전체 Frame을 시간순으로 표시하며, 실제 본문 폭에 따라 4열·2열·1열로 전환한다. DOM·키보드 순서는 시간순이다. 장비 베이스 이미지는 표시하지 않는다. 32px 화폐·소비 징조 아이콘은 화살표 위에, 화폐 이름·반복 횟수는 아래에 표시한다. 상태 카드와 연결 화살표를 같은 흐름으로 읽을 수 있으며 원시 JSON·내부 identity·중복 기보 목록은 본문에 표시하지 않는다.

화폐·소비 징조·반복 횟수·장착 Rune 라벨은 기존 기보의 `NotationResources`와 동일하다. 관측 및 미확인 action도 상태를 생략하지 않는다. 반복 Chaos의 저장되지 않은 중간 상태를 복원하지 않는다. 현재 ruleset과 상태 검증이 모두 통과할 때만 현재 catalog로 옵션을 표시한다. 다른 규칙의 표시 가능한 저장값과 전체 원본은 보존한다. 기존 Augment ID·품질·심연·축성·원문·미해석 관측값·알려지지 않은 확장 데이터도 파일에서 유지한다.

작업대·제작 지원·관리·오버뷰는 같은 실제 외곽 폭과 좌우 여백을 사용한다. 작업대의 기존 75% 축소 배치는 유지하고, 나머지 페이지는 동일한 표시 폭에 맞춘다. 작은 화면에서는 화면 폭을 사용한다. 오버뷰에는 별도의 작업 공간 내비게이션·언어 선택기를 표시하지 않으며 현재 선택 언어를 유지한다. 모든 문구는 기존 6개 locale을 지원한다.

## JSON 파일

세션 라이브러리 상단에서 JSON을 가져오고 각 기록에서 해당 세션을 내보낸다. 내보내기는 활성 세션을 바꾸지 않고 저장이 차단된 경우에도 사용할 수 있다. 가져오기는 전체 흐름 미리보기와 명시적 확인을 거친다. 저장에 성공하면 히스토리 탭에서 가져온 세션을 선택해 미리 보여주며 현재 시뮬레이션은 유지한다.

`exile-session`, `version: 1` JSON은 `exportedAt`과 전체 `film`을 담는다. UTF-8 2,000,000 bytes, 2,000 Frames, 깊이 32, 노드 100,000 한도이며 위험한 prototype 키·미지원 schema·잘못된 기본 구조는 거부한다. 게임의 실제 획득·화폐 소비 증거를 인증하는 형식이 아니다.

같은 ID·동일 내용은 기존 기록을 유지하고 다른 내용은 새 ID를 부여한다. 원래 ID는 Film 내부 필드를 덮어쓰지 않고 바깥의 `Films.importSources`에 보존한다. 충돌 때문에 ID를 바꾼 파일을 다시 가져와도 기존 복사본을 유지한다. 기존 세션·활성 선택·원래 저장 bytes를 보존하고 기존 저장소 한도와 반복 receipt 검증도 거친다. 원문을 임의로 삭제·보정하지 않는다.

## PNG

화면에 렌더된 제작 흐름 DOM의 computed style·실제 이미지·폰트·줄바꿈을 유지해 PNG로 캡처한다. 텍스트나 카드를 별도로 재작성하지 않는다. SVG 화살표는 화면의 같은 벡터를 측정 크기로 래스터화해 포함한다. Desktop·Mobile 각각 현재 배치 그대로 저장한다. 소수점 좌표의 외곽 픽셀도 화면 캡처와 같은 경계로 포함한다.

긴 흐름은 완료된 카드 행 경계에서만 분할하며, 행 사이 방향 전환은 다음 페이지에 온전히 포함한다. 한 장이면 `session.png`, 여러 장이면 `session-1.png`, `session-2.png` 순서로 모든 PNG를 바로 다운로드한다. 다운로드 내역이나 개별 다운로드 링크, 중복 이미지는 표시하지 않는다. 크기·pixel 예산을 초과하면 일부 기록을 자르지 않고 실패를 알린다. 원본 복원은 JSON import/export를 사용한다.
