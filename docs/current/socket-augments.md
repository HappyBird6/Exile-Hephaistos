# 소켓과 증강물

등록 수·선택 가능 수·언어는 [지원 범위](support.md)의 자동 생성 요약을 따른다. 실행 원본은 `backend/src/main/resources/catalog/augments.json`이며 프런트 복사본은 `node scripts/sync-workbench-data.mjs --write`로 갱신한다.

## 장착과 제작 규칙

`augment-crafting.json`이 홈 귀속, 제작 속성 한도, 접미 한도, 최대 품질, Rune 효과, Idol 결속, 특수 옵션 풀의 원본이다. `AugmentCraftingRules`와 프런트 공용 규칙은 이 정의를 소비한다. 장착 ID·장비 분류·실제 슬롯·동일 아이템 제한을 검증하며, 캐릭터 전체 장비 제한은 계산하지 않는다.

Perfect 선택 정책으로 숨긴 하위 Rune도 기존 저장 기록에서는 보존한다. 홈 귀속 항목은 일반 교체에서 제거할 수 없다. 이미 생성한 Crafted 옵션 및 보존 대상으로 정한 초과 품질은 증강물 제거만으로 삭제하지 않는다. 특수 풀의 원래 정의는 보존하고 장착 시 가중치와 자격을 활성화한다.

장비 합계와 옵션 배율은 공통 효과 계산을 사용한다. 결속은 명시적 상태이며 캐릭터 전체 전투 시뮬레이션을 뜻하지 않는다. 알두르 원소 변환 등 아직 보류한 동작을 표시만으로 지원한다고 추정하지 않는다.

## 근거와 갱신

[이전 수집 대조표](augment-catalog-audit.md)와 evidence 원문은 당시 자료다. 현재 지원 정책을 과거 보류 목록으로 덮어쓰지 않는다. `prepare-socket-catalog.py` 및 `expand-augment-catalog.py`는 이제 현행 원본과 근거 ID를 읽기 전용으로 검증한다.

새 증강물은 출처와 규칙을 검토해 백엔드 원본에 반영하고, 프런트 복사본·규칙 manifest·생성 요약을 갱신한다. 새 동작은 수치 데이터만 추가해서 구현되는 것으로 간주하지 않는다. 일반/훼손 제작·확률·저장 복원·텍스트·스냅샷의 관련 계약 검사를 수행한다.
