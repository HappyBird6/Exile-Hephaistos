# 불일치와 비교 검증

**사람의 검토용 문서이며 기본 RAG 검색 대상이 아니다.** 아래에는 오래된 기대값과 미결정 사항이 포함된다. 이를 현재 사용 가능한 전략으로 인용하지 않는다.

## 추출에서 구분한 불일치

| 항목 | 확인한 내용 | 이번 문서 처리 |
|---|---|---|
| 카오스의 옵션 개수 | 초기 원장에는 실제 명시 속성 총 1개. 후속 지시/코드는 분열 제외 변경 가능한 속성 1개 | 최신 조건 추출. 미공개 훼손도 개수에 포함하되 전이 지원은 별도 검사 |
| 제왕의 사용 목적 | 정책 JSON 설명은 임시 추가만 언급. `evaluate`는 목표 획득도 허용하며 직접 제왕 추천 검사 통과 | 실행 동작을 추출하고 차이 명시. 설명만 보고 직접 제왕 후보를 제거하지 않음 |
| 마무리 엑잘 | 과거 일반 획득 설명과 이후 엄격 제한이 다름 | 첫 카오스 준비/제거용 더미 조건과 후속 교체 강제만 추출 |
| 절사·좌/우 말소 | 준비 코드·문구·역사 테스트가 있지만 현재 정책은 DEFERRED | 기본 전략 문서에서 활성 경로로 추출하지 않음 |
| 훼손 세 전략 | 별도 추천 코드와 공통 DESECRATE 주 경로가 함께 남음 | 주 경로는 활성 문서, 별도 추천은 reference에 보존 |
| 품질 작업 | 실제 화폐/기폭제 적용과 추상 20/40 작업이 다름 | 추상 작업·상한·종료·소모 ID를 명시. 가격/개수/효과를 새로 추정하지 않음 |
| 징조 inventory의 장비 문맥 | 후보 구성 시 `amulets`가 하드코딩, kernel은 실제 family로 재검사 | 사실을 명시하고 원본 동작 유지. 이번 문서 작업에서 수정하지 않음 |
| 프런트 설명·선택 | 장비별 정책 안내·Rare 목표 정규화·100회/과거 관측 값 등이 별도 코드에 존재 | RAG 문서만 바꿔 기존 화면 정책까지 자동 갱신된다고 가정하지 않음 |

전체 원장을 검색 지식으로 넣으면 대체된 지시가 다시 추천될 수 있다. 활성 문서는 최신 적용 조건만 담고, 이번 문서는 검색 허용 목록에서 제외한다.

## 직전 관련 검사

추출 직전 코드 `859a29b3`에서 다음 7개 클래스의 48개 테스트를 실행했다. **46개 통과, 2개 실패**다. 문서 추출 후 새 RAG 경로를 실행한 결과가 아니며 전체 앱 검사도 아니다.

| 클래스 | 실행 / 실패 |
|---|---|
| `AutomaticCurrencyPolicyTest` | 7 / 0 |
| `AutomaticPreparationRulesTest` | 5 / 1 |
| `GoalDirectedPlannerScenariosTest` | 22 / 1 |
| `AutomaticAbyssSearchTest` | 4 / 0 |
| `AutomaticNormalStartTest` | 1 / 0 |
| `AutomaticQualityGoalsTest` | 6 / 0 |
| `CommonDesecrationGraphTest` | 3 / 0 |

실패 의미를 구분한다.

1. `chaosPreparationUsesExactlyOnePlainExaltOrRegalWithoutAssumingEqualProbabilities`: Rare 빈 시작의 엑잘→카오스는 생성되지만, Magic 1옵션의 제왕→카오스는 생성되지 않는다. 후자는 제왕 후 변경 가능 옵션 2개가 되어 현재 정책과 충돌한다. 기존 검사 기대값을 현재 정답으로 복사하지 않는다.
2. `fracturedWhittlingRemainsUnverifiedRatherThanRenormalized`: 과거 정책 fixture에서 분열 옵션만 있는 상태를 넣었을 때 예전 `UNSUPPORTED` 기대와 현재 `UNAVAILABLE`가 다르다. 제거 가능한 옵션이 없다는 실제 이유를 확인했다. 이것은 현재 보류된 절사를 활성화할 근거가 아니다.

임시 소형 카탈로그 프로브에서도 위 두 상태와 제왕 `GOAL_ACQUISITION=PERMITTED`를 확인했다. 프로브는 저장소에 추가하지 않았다. 신규 구현 시 기대값 변경은 별도 판단하고, 현재 정책 회귀와 과거 정책 보존 검사를 나눈다.

## 동등성 비교용 사례 목록

아래 목록은 추가 비교 검사의 설계이며 이미 RAG 경로에서 통과한 테스트가 아니다.

| 사례 ID | 같은 입력으로 비교할 것 |
|---|---|
| E01 | Rare 빈 시작의 징조 없는 엑잘 직접 후보와 엑잘→카오스 준비 후보 |
| E02 | Rare 분열 A + 일반 비목표 B: 처음에는 카오스 후보, 같은 아이템의 후속 단계에서는 제외 |
| E03 | 분열 A만 남은 시작의 준비 후보와 분열 A + 일반 B/C의 카오스 제외 |
| E04 | 일반 목표를 이미 획득한 상태와 분열 목표만 획득한 상태의 차이 |
| E05 | 마법 1옵션→제왕의 실제 결과가 두 변경 가능 옵션이면 카오스 준비 제외 |
| E06 | 엑잘 더미 좌/우 징조, 실제 더미 소비 분기의 존재, 준비 중 성공에도 후속 교체 유지 |
| E07 | 제왕 직접 획득·동일 분포 징조 제외·확정 성공 징조 제외·동률 순서 |
| E08 | Normal 목걸이의 준비 연결과 결과가 없을 때 단독 진화, 연금술/비목걸이 제외 |
| E09 | 품질 20 작업, 20 초과 상한→40 작업, 상한 잔존, 이미 40일 때 중복 작업 없음 |
| E10 | 품질 준비 중 기존 목표 교체와 상한 제거 미해결 질량 |
| E11 | 공통 훼손 후보의 순서·슬롯·분열 보존, 엄격 엑잘 유지, 관측 전 미해결 경계 |
| E12 | UNKNOWN/UNSUPPORTED 목표에서 후보 없음과 도달 불가 판정 구분 |
| E13 | 같은 후보의 순서/예산/확률/소모량 및 저장·복원 후 결과 비교 |
| E14 | 제외/보류 화폐, 참고용 훼손 전략, 과거 문서가 검색 결과로 활성화되지 않음 |
| E15 | 필요한 전략 검색 누락·잘못된 후보 기각·기존 코드 대체를 성공으로 숨기지 않음 |

확률·분수·옵션풀·게임 자격을 문서에서 재구현하지 않는다. 기존 엔진을 공통으로 사용한 비교에서 후보 구성과 종료 의미의 차이를 먼저 찾는다. 동일 결과가 나와도 불필요한 AI 호출이 그래프 노드 수에 비례해 늘지 않는지 별도 측정한다.

## 추출 이후 구현할 일

1. 이 문서 묶음의 필요한 문맥과 조건을 기존 코드에서 제공하는 경계를 정한다.
2. 문서를 검색/활용해 기존 `Choice(initial, cycle)` 의미로 변환하는 별도 비교 경로를 만든다. 이 문서 작업에는 로더·LLM·벡터 DB가 포함되지 않는다.
3. 후보 누락·추가·순서, 준비 성공/후속 교체, 확률/소모량, 저장 복원을 비교한다.
4. 알려진 불일치의 처리 방침과 실제 동등성 범위를 보고한 뒤 전환 범위를 정한다.

신규 화폐 허용·비용 최적화·목표 모델 확장은 이후 별도 변경으로 다룬다. 그 작업을 동일 동작 이관에 섞으면 차이의 원인을 구분하기 어렵다.
