# 지원 범위

현재 지원하는 기능은 제작 작업대의 재료 표시·선택·검색·즐겨찾기와 영어 아이템 복사 텍스트 분석이다.
`POST /api/v1/items/parse`는 원문·미해석 행·경고를 보존한다. catalog 검증 및 계산용 ItemState 변환은 지원하지 않는다.

지원 시즌·패치·Base·Modifier·Currency 규칙·handler는 아직 확정되지 않았다. 화면의 재료 목록은 실제 제작 지원 목록이 아니다. 화폐 소모·옵션 변경·확률 계산은 수행하지 않으며, 데이터 누락을 0% 또는 지원 완료로 표시하지 않는다.
