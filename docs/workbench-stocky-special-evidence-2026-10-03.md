# Stocky special crafting evidence matrix (2026-10-03)

This audits the **13 rows / 12 material identities** in the current strength-glove `perfect_essence` array. The separately captured basic `essence` array has 50 variant rows, not 50 supported materials. Neither array is complete game inventory or proof of obtainability. This matrix is supporting evidence; unresolved work belongs only in root ISSUES.md.

All 13 actual source Codes have individual current PoE2DB detail responses captured in `codex/qa-20261003/stocky-next-special-detail-proof.json`: row, exact public detail URL, timestamp, HTML, source stat caption/bounds/locality. The shared Hysteria/Abyss item pages and ten remaining item pages were also fetched independently, not inferred from array placement. Page evidence: `stocky-next-special-source-review.json`, `stocky-special-item-page-proof.json` and their named HTML files. The item-page manifest retains raw selected blocks plus `materialBlocks` limited to the first material card: Horror also has a same-name monster page section, whose skill stats are deliberately excluded from material rules. No executable page code is run when extracting these blocks.

Bounds below are **raw published source bounds**, not proof of integer step/display precision/distribution. A fixed target has selection probability 1; variable numeric domains would retain the reversible WB-003 model if activated. The two Abyss affix outcomes have no published relative choice weights and use the existing explicit 1/2 assumption, after proving the complete two-target set. These special source rows show zero ordinary spawn; that is not a special-selection weight. Special-only zero-spawn definitions must never enter weighted ordinary addition pools. Hysteria independently matches the ordinary of Fury definition; its published normal weight 500 remains intact and is not replaced by the special-row zero.

## Applicability and implementation order

1. Hysteria is already activated on Stocky; Abyss's two equipment-wide Mark outcomes are the current v20 extension. See [Abyss catalog/snapshot validation](workbench-stocky-abyss-2026-10-03.md) and [Hysteria](workbench-stocky-hysteria-2026-10-03.md).
2. **Horror is the next simplest independent candidate:** current item page explicitly says Gloves or Boots, fixed 60% socketed Augment Item effect, Rare removal + guaranteed addition. Detail `EssenceLocalRuneAndSoulCoreEffect1` is a level-1 suffix, family SoulCore, fixed Local stat caption `local socketed items effect +%` 60..60. Add a reviewed dedicated zero-spawn definition/action and preserve the complete removal-branch/Crystallisation/Fracture tests. A stored modifier's sourced effect can be represented independently of socket/augment computation; the current Workbench does not calculate affected socketed stats or invent an extra socket prerequisite. Audit any actual additional use requirement before activation.
3. **Perfect Grounding and Perfect Opulence:** item pages explicitly give Gloves results matching the individual details. Source levels are 72, effects are lightning damage recoup 26..30 and enemy Gold quantity 10..15. Review dedicated target identity and keep the unverified numeric-grain/display label; exact end points do not establish random distribution. Their effects do not establish currency removal weights.
4. **Seven distinct Alloys:** individual pages give glove results for Adaptive/Expansive/Swift/Cyclonic/Prismatic/Mystic. Adaptive's missing Runic Ward is the modifier's conditional effect, not an inferred currency-use prerequisite. Do not simulate character Runic Ward/combat behavior from absent state. Swift has **two families**, IncreasedCastSpeed and IncreasedAttackSpeed; any existing overlap in either must be checked. Sovereign says Armour gets Runic Ward increase; its current exact glove stat is **Local** `local ward +%` 24..30. No extra 'Runic Armour only' rule or Stocky computed Ward total is assumed. Underlying property/display/quality/socket scaling remains separate from representing a sourced modifier; confirm applicable base/use requirements before implementation.
5. **Solar comparison:** these glove-row outcomes must not be copied to Solar. Several Alloy pages list other equipment results; Sovereign's Jewellery/Belt result instead scales Explicit Resistance Modifier magnitudes, requiring a distinct source target and scaling boundary. No Solar support is claimed from the glove Codes. Current Perfect Enhancement/Perfect Infinite/Breach/Runic pages remain Amulet/Jewellery results in the earlier audit; they are separate material identities.

No new base is needed for these priorities. Map/skill-gem crafting, Vaal and Hinekora retain the user's exclusions. Stocky basic Infinite remains blocked by WB-010 because its complete eligible attribute outcome set is unknown; this audit does not settle it. WB-003 numeric models and WB-004/WB-005 scaling/special-state gaps remain open. Registered inventory is not implementation: scope counts come from actual registry/action APIs, never from this row table.
