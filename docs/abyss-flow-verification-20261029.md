# 심연 일반 제작 흐름 검증 — 2026-10-29

## 구현

- 일반 제작 다음 작업에 한쪽 채우기·고가중치 차단·제거 위험 분산 전략을 직접 표시한다. 별도 심연 펼치기 버튼을 제거했다.
- 같은 그래프에 미공개 슬롯, 세 관측 후보, 사용자 선택, 화폐 적용 상태를 추가한다. 관측/선택은 점선과 확률 미정 표시이며 기존 자동 확률 집계에는 넣지 않는다.
- 후보 확정 후 같은 목표의 일반 탐색으로 이어진다. 이전 수동 단계와 새 탐색이 연결되며 훼손 메타데이터와 분열을 유지한다. 브라우저 재로드 복원을 제공한다.
- 현재 시나리오 공유 코드는 일반 탐색 구간만 포함한다. 심연 이력은 브라우저 복원 범위이며 UI에 명시한다. 확률 근거 없는 후보의 자동 최적화·전체 기대비용은 제공하지 않는다.
- 분포 상태와 과거 읽기 전용 시나리오를 임의의 구체 상태로 바꾸지 않는다. 확인되지 않은 Whittling+분열 지원은 확장하지 않는다.

- 심연 컴포넌트를 mock하는 제안은 자동 승인 검토에 거절되어 실행되지 않았다. 실제 Provider 추가 방식으로 해결했다.
