# 제작 기능의 근거 자료

현재 관리 버전은 **0.5.5**다. 자료는 [0.5.5 기능별 안내](0.5.5/README.md)에서 찾는다.

아이템 종류나 작업 날짜 대신 번역·카탈로그·제작·화면·도구 등 기능을 기준으로 분류한다. 이전 버전의 수집 시각·실행 로그·배포 결과와 외부 백업 목록은 유지하지 않는다. 옵션 수치·가중치·언어별 원문·URL·내용 해시는 현재 사용하는 데이터와 도구의 입력으로 남긴다.

폴더의 버전은 현재 프로젝트의 관리 범위다. 개별 원자료가 0.5.5 게임에서 새로 검증됐다는 뜻은 아니며, 게임 규칙 확인 상태를 임의로 VERIFIED로 바꾸지 않는다.
