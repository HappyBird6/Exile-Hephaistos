# 주얼 한도 초과 상태의 카오스 적용

2026-11-04 사용자 지정 규칙을 적용한다. 접두/접미 최대치 +1 속성이 제거되어 현재 한도를 초과한 쪽은 카오스 교체 후보에서 제외한다. 예를 들어 접두 3/2, 접미 2/2인 상태에서는 접두의 원본 옵션과 값을 보존하고 접미만 교체한다. 반대 방향도 동일하다.

- 일반·상위·완벽한 카오스 및 반복 사용이 동일한 후보 규칙을 사용한다.
- 미공개 훼손 슬롯도 점유 수에 포함한다. 보호되는 슬롯의 ID·표식·후보 풀·최소 레벨을 보존한다.
- 현재 +1 속성이 남아서 3/3으로 정상인 쪽은 보호 대상이 아니다.
- 초과 보호 → 징조의 접두/접미 제한 → 깎기의 징조 최저 옵션 레벨 순서로 후보를 좁힌다. 서로 충돌해 후보가 없으면 적용하지 않고 활성 징조도 소모하지 않는다.
- 소멸의 오브에는 이 보호를 적용하지 않는다. 초과 옵션을 실제로 제거하면 영구 확장은 남지 않는다.
- 추가 옵션은 현재 접두·접미 한도, 충돌 그룹, 화폐의 옵션 레벨 및 기존 가중치를 따른다. 신규 확률이나 실패 소모 모델은 추가하지 않는다. 제거 후보 간 균등 선택은 종전 시뮬레이터 모델 그대로이며 게임의 공개 확률로 주장하지 않는다.
- 프런트 단일 사용·심연 사용·반복 응답 검증에서도 보호 대상의 수치나 슬롯이 변한 결과를 거부한다. 기존 세션 저장 형식은 바꾸지 않는다.

주얼 규칙 식별자는 `basic-jewel-potent-v5-five-affix-chaos-overflow`, 고대 주얼은 `time-lost-ancient-v3-five-affix-chaos-overflow`로 변경한다. 이전 기록의 규칙 문자열은 재작성하지 않는다.

검증 대상은 8종 베이스의 양방향 초과, 세 카오스 등급, 미공개 슬롯, 징조 충돌 및 소모, 깎기의 징조, 소멸 이후 정상 한도 복귀, 1,000회 반복, 실제 API와 프런트 클라이언트의 저장·복원이다. 브라우저 자동 검증은 사용자 요청으로 보류한다. 검증 결과와 서버 자산·사용자 기록 보존 증거는 작업 전용 임시 검증 디렉터리에 보관한다.
