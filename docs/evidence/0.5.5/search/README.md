# 제작 방법 탐색과 확률

`probability/sources`에는 복합 roll을 해석한 원본 정의와 모델 경계가 있다. 옵션 원문·수치·가중치는 `../catalog`와 언어별 `../i18n`을 함께 사용한다. 아이템별로 같은 원문을 다시 복제하지 않는다.

- 단일 전이: [기본 화폐 전이](../../../basic-currency-transitions.md).
- 최초 성공·복구: [first-hit 계약](../../../basic-currency-first-hit.md).
- 현행 자동 탐색: [자동 명세](../../../current/automatic-planning.md).
- 구형 bucket/certified 엔진: [method 계약](../../../crafting-bucket-method-v2.md).

새 측정 자료는 transitions/first-hit/automatic/probability에 실제 검증 범위를 표시해 둔다. 관리 버전 0.5.5나 파일 이동 자체가 실제 게임 확률·결합 분포·전체 경로 완료의 증거가 되지는 않는다.
