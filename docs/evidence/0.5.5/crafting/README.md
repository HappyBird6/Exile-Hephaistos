# 제작 규칙의 근거

- `abyss`: 드러내기 정의·슬롯과 후보의 출처다.
- `quality`: 품질 상한과 보존 규칙의 근거다.
- `sanctification`: 원문 캡처와 정확한 local 방어 stat ID 감사다.
- `sockets`: 소켓·품질 관련 원문의 의미와 적용 범위다.
- `essence`: 에센스의 실제 대상과 추가 근거가 필요한 범위다.

현재 사용자 정책과 simulator 동작은 `docs/current/user-crafting-rules.md` 및 `docs/development.md`를 따른다. 과거 수집 이력은 남기지 않으며, 원문에 없는 확률·게임 규칙을 보충하지 않는다.
